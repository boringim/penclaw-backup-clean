- 已实现并验证的能力包括：单步命令（open / snapshot / text / screenshot / extract-links / click-by-text / fill / wait-for-text / google-probe）以及会话命令（session-open / status / goto / text / html / extract-links / click-by-text / fill / press / wait-for-text / screenshot / eval / close / list）。
- 会话实现最终采用“127.0.0.1 本地 HTTP 控制面 + 进程内常驻 page/context + 随机 token”的方式，比 `launchServer/wsEndpoint` 更稳定，真正保住了同一页面状态的连续操作能力。
- 已验证持久 profile 能力：支持 `session-open --profile <name>`，profile 落在 `C:\Users\Administrator\.openclaw\experiments\camoufox-wrapper\profiles\...`，与日常真实浏览器数据隔离。
