### 技术问题
- Amazon：后台访问 `https://www.amazon.com/s?k=cat+grooming+brush` 时稳定返回 `Sorry! Something went wrong!`，页面无正文商品数据，仅有 3 个错误页链接。
- AliExpress：后台访问 `https://www.aliexpress.com/wholesale?SearchText=cat+grooming+brush` 时稳定被重定向到 `punish / x5secdata / x5step=1` 风控链路，无法直接提取商品信息。
- 当前判断：这两个平台的拦截都已经超出“轻度指纹问题”范畴，继续纯后台重试收益很低，必须依赖人工验证/登录/区域确认后再复用前台会话或持久 profile。

- Camoufox + 自建会话控制层在部分平台（如 Alibaba）已经足够实用，但在 Amazon / AliExpress 这类高风控站点上，单靠后台无头/半持久 profile 仍不足以稳定跨过错误页与风控页。
